# Traffic Torch AI SEO Toolkit for Framer

**Instant 360° AI SEO, AEO & UX Health Analysis Toolkit** — Official Framer plugin.

Bring the full power of [Traffic Torch](https://traffictorch.net) directly into the Framer editor. Launch any of the 17 AI-powered AEO, SEO & UX tools with one click, using your published Framer site URL (or any public URL).

### Core Features
- Clean dropdown with all 17 Traffic Torch tools (exact order + emojis)
- Smart auto-detection of your published Framer site URL
- Big green “Launch Tool with URL →” button
- Clear educational warnings about Framer preview URL limitations
- Full day/night mode support (gray-800 in light mode / dark gray-200 in dark mode)
- Mobile-friendly layout, PWA-ready structure
- Non-spammy, educational UX that matches traffictorch.net
- All tools now include CMS-specific fixes and Ask AI features
