# Traffic Torch for Framer

**Instant 360° AI SEO, GEO & UX Health Analysis Toolkit** — Official Framer plugin.

Bring the full power of [Traffic Torch](https://traffictorch.net) directly into the Framer editor. Launch any of the 13 AI-powered GEO & SEO tools with one click, using your published Framer site URL (or any public URL).

### Core Features
- Clean dropdown with all 13 Traffic Torch tools (exact order + emojis)
- Smart auto-detection of your published Framer site URL
- Big green “Launch Tool with URL →” button
- Clear educational warnings about Framer preview URL limitations
- Full day/night mode support (gray-800 in light mode / dark gray-200 in dark mode)
- Mobile-friendly layout, PWA-ready structure
- Non-spammy, educational UX that matches traffictorch.net
